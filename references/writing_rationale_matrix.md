# Writing Rationale Matrix

The Writing Rationale Matrix is the execution plan for prose. Create it before
section drafting.

## Required Table

| Row ID | Manuscript Unit | Planned Function | Motivation Link | Exemplar or Venue Pattern | Evidence or Citation Anchor | Planned Text Move | Final Text Check |
|---|---|---|---|---|---|---|---|

## Unit Granularity

Use the smallest useful writing unit:

- Abstract move.
- Introduction paragraph.
- Methods subsection.
- Result claim unit.
- Figure caption.
- Discussion interpretation paragraph.
- Limitation paragraph.
- Clinical or translational implication paragraph.

## Rules

- The first row must justify the whole-paper throughline.
- No row may say only "improve clarity" or "polish language".
- Each row must explain how the unit advances the confirmed motivation, uses
  evidence, follows target venue norms, or manages reviewer risk.
- If a paragraph contains multiple claims with different evidence anchors,
  split it into multiple rows.
- The final text check must be concrete, such as "no causal wording", "links to
  Figure 2", "cites verified review", or "states limitation before implication".
