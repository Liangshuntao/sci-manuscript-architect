# Journal Checklist

Use this file for submission readiness and reporting-guideline selection.

## Guideline Selection

| Study Type | Primary Guideline | Use When |
|---|---|---|
| Randomized controlled trial | CONSORT | Human intervention trial with randomization |
| Observational cohort/case-control/cross-sectional | STROBE | Observational human or population study |
| Systematic review/meta-analysis | PRISMA | Evidence synthesis with systematic search |
| Animal study | ARRIVE | In vivo animal experiment |
| Prediction/prognostic/diagnostic model | TRIPOD | Model development or validation |
| Diagnostic accuracy study | STARD | Diagnostic test accuracy |
| Case report | CARE | Single case or small case report |

## LaTeX-Safe Checks

- Citation keys exist in the bibliography.
- Figure files are present and paths match source.
- Labels are unique and referenced correctly.
- Special characters in title, abstract, captions, and author fields are escaped.
- Tables fit the target format or are marked for manual formatting.
- Missing compiled PDF is reported as skipped, not as passed.
