# PaperSpine Map

The PaperSpine Map turns motivation into a manuscript argument. It is not an
outline; it is the logical backbone of the paper.

## Required Table

| Element | Draft Content | Evidence Anchor | Risk |
|---|---|---|---|
| Research context | Field and problem setting | Citation or user material | |
| Specific gap | What remains unresolved | SOTA or target journal context | |
| Study objective | What this study tests, develops, or demonstrates | User protocol or design | |
| Central claim | Main conclusion the evidence can support | Key data or figure | |
| Main finding | Most important result in plain terms | Figure/table/statistic | |
| Novelty | What is new relative to known work | Citation support | |
| Mechanistic or explanatory claim | Only if supported | Mechanistic data | |
| Practical implication | Conservative implication | Evidence plus literature | |
| Take-home message | One final sentence | Whole evidence set | |

## Rules

- The central claim must be narrower than the total dataset.
- Every novelty statement needs a comparator: prior method, prior population,
  prior mechanism, prior model, or prior limitation.
- Avoid "first", "novel", "significant", and "promising" unless the evidence
  and literature search justify them.
- The take-home message should be memorable but not promotional.

## Output After the Table

Add a short Chinese diagnosis:

- `主线是否清楚`
- `最弱证据环节`
- `最容易被审稿人攻击的 claim`
- `建议优先补强的数据或表述`
