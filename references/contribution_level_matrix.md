# Contribution-Level Matrix

## Purpose

Use this reference to decide how strong the project's contribution is relative
to the field. This sits between innovation classification and journal strategy.

## Contribution Levels

| Level | Meaning | Typical journal implication |
|---|---|---|
| Confirmatory | Replicates or supports known biology in a new cohort/context | Lower-level or niche specialty |
| Incremental | Adds a modest dataset, subgroup, assay, or analysis angle | Solid specialty if rigorous |
| Solid advance | Provides a clear new biological, clinical, or method insight with validation | Strong specialty or selected higher-impact |
| Field-shaping | Changes how the field frames a problem or mechanism | High-impact candidate |
| Translationally important | Links mechanism or biomarker to clinical decision, therapy, target, or guideline-relevant need | High-impact or translational journal candidate |

## Evaluation Axes

Score qualitatively:

- Field need: weak, moderate, strong, urgent.
- Novelty: known, incremental, new angle, major new concept.
- Evidence strength: descriptive, associative, validated, causal, clinical.
- Scope: single dataset, multi-cohort, multi-modal, independent validation,
  clinical translation.
- Reusability: none, analysis insight, resource/tool, benchmark, clinical
  workflow.
- Fit to target journal: poor, plausible, strong, stretch.

## Output

Produce a matrix with:

- Current contribution level.
- Why it is not one level higher.
- Evidence or analysis needed to upgrade the level.
- Safest claim wording.
- Target journal tier recommendation to pass to
  `submission_level_estimator.md`.
