# Motivation Lock

Use this reference before drafting. The goal is to identify one controlling
reason the paper exists.

## Required Output

Create a concise Motivation Lock with:

| Field | Content |
|---|---|
| Clinical or biological problem | The real problem motivating the work |
| Knowledge gap | What current studies do not explain or solve |
| User evidence | The strongest result or material supplied by the user |
| Central motivation | One sentence that connects gap, method, and contribution |
| Scope limit | What the paper must not overclaim |
| Evidence boundary | What can be claimed now versus what needs more data |
| Confirmation status | `confirmed`, `needs user confirmation`, or `assumed` |

## Rules

- Prefer one controlling motivation over multiple loosely related claims.
- If novelty is narrow, state it narrowly.
- Do not turn a preliminary observation into a mechanism unless the user
  provides mechanistic evidence.
- If the user has not confirmed the motivation, continue with planning but mark
  the motivation as `needs user confirmation`.

## Motivation Quality Check

A strong motivation should:

- Name the problem and gap without hype.
- Be supported by at least one user-provided result or material.
- Explain why the study deserves a manuscript.
- Predict the paper's Introduction and Discussion arc.
- Define forbidden overclaims.
